SCHOOLHUB WEBSITE — SHARED HOSTING PACKAGE

Upload every file in this folder to the public web root for schoolhubug.com (often public_html).

Before publishing:
1. Complete config.js with DualHub Technologies Uganda's email, digits-only WhatsApp number and secure form endpoint.
2. Replace all bracketed contact, founder, developer, testimonial and legal placeholders with verified information.
3. Add real founder/developer photos only with permission and optimize them as WebP.
4. Add only verified, approved testimonials.
5. Have the draft legal pages reviewed for the actual business and data practices.
6. Confirm plan inclusions, tax wording, annual discount and all prices.
7. Connect formEndpoint in config.js to a secure HTTPS endpoint that validates input and rate-limits requests. Email fallback is supported when contactEmail is set.
8. Review the legal pages against DualHub Technologies Uganda's actual practices and applicable Ugandan law.
9. Test both forms and all contact links on the live HTTPS domain before advertising it.

The bundled Ugandan school photographs are AI-created illustrative scenes and are disclosed on the page. They do not represent actual customers or endorsements.

Files:
- index.html — main website
- styles.css — all styles and responsive layouts
- config.js — launch contact and form-delivery settings
- script.js — navigation, animations, pricing, validation and cookie choice
- privacy-policy.html, terms.html, cookie-policy.html — legal drafts
- 404.html — custom error page
- robots.txt and sitemap.xml — search engine files

No build step is required. This package uses only HTML5, CSS3 and vanilla JavaScript.
